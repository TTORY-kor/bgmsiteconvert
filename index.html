폴더 ↔ 시나리오

BGM Manager 폴더는 TRPG Watch 시나리오로 변환됩니다. 여러 폴더에 속한 곡은 각 시나리오에 포함됩니다.

YouTube 주소 ↔ ID

watch, youtu.be, shorts, embed 주소를 분석해 영상 ID를 추출합니다. 역변환할 때는 표준 watch 주소를 만듭니다.
